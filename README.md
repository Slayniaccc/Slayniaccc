### Featured

**[Eyes On The Sky](https://github.com/Slayniaccc/EyesOnTheSky)** — [play it](https://slayniaccc.github.io/EyesOnTheSky/)  
*Vanilla JS · Phaser 3 · PWA*

A tablet-first educational game putting Year 6 pupils in the seat of a WAAF plotter during the Battle of Britain. Six scenes walk the real Dowding System end to end — radar detection, the tote board, the Decision Room, the intercept — so the chain of command is something you operate rather than read about. Built offline-first for school tablets: Phaser is vendored locally instead of CDN-loaded, a service worker precaches every asset, and missing audio degrades silently rather than throwing.

**[Who Needs You Most](https://github.com/Slayniaccc/who-needs-you-most)** — [play it](https://slayniaccc.github.io/who-needs-you-most/)  
*Vanilla JS · Phaser 3 · Web Audio API*

An eight-minute D-Day game for Year 6, played as Elsie, an Allied Army nurse landing in Normandy. One mechanic — triage — across five escalating waves. The design constraints did most of the work here: no fail state, no score, no depicted injury, no combat, because turning triage into an optimisation puzzle would undercut the scene. All SFX and ambience are synthesized with the Web Audio API rather than pulled from a library.
