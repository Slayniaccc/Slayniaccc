**[Eyes On The Sky](https://github.com/Slayniaccc/EyesOnTheSky)** — [play it](https://slayniaccc.github.io/EyesOnTheSky/)
*Vanilla JS · Phaser 3 · PWA*
Tablet-first educational game putting Year 6 pupils inside the Dowding System during the Battle of Britain — radar, tote board, Decision Room, intercept. Offline-first: vendored assets, service-worker precaching, silent audio fallback.
