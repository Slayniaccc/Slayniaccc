## Featured

### [Sports Conflict Tracker](https://github.com/Slayniaccc/Sports-Conflict-Tracker)
*Java 21 · Spring Boot · Postgres · Flyway · React · TypeScript · Tailwind · Docker · GitHub Actions*

Your teams play at the same time. Which one do you watch? It syncs NBA, NFL, MLB and EPL fixtures, flags the clashes, and ranks every game with a score and a reason you can read.

A framework-free Java rule engine scores rivalry intensity, playoff stakes, home advantage and your favourite team, with Spring wrapped around it rather than through it. JWT auth, Testcontainers in CI, and a redesigned React frontend. Next up: results, form and standings.
